# Legacy figures (not in the journal figure set)

Exploratory plots of the first Si(111) buried-dislocation smoke test (docs/08), kept as the
record of that run. They predate the Nature-style figure set in `docs/figures/` and the sampling
convergence study. The multislice panel uses a lateral pixel of 0.39 A, at which the specular
reflectivity is not converged (docs/08, correction; `fig_convergence`). Do not use them in
publications. They will be regenerated in the journal style if the Si(111) case is pursued.
